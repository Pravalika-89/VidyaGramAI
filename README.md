# 🌾 VidyaGram AI

## AI Village Education & Career Assistant

VidyaGram AI is an AI-powered web application that helps students explore career opportunities through Machine Learning and Google Gemini AI. It provides career prediction, AI-based guidance, personalized roadmaps, quizzes, progress tracking, and resume generation.

## 🚀 Features

- User Registration & Login
- AI Career Assistant (Google Gemini)
- Machine Learning Career Prediction
- Career Roadmaps
- Career Information
- Match Score
- Career PDF Report
- Resume Builder (PDF)
- Learning Hub
- Quiz Module
- Progress Tracker
- Dashboard Analytics
- User Profile

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- Scikit-learn
- Google Gemini AI
- HTML
- CSS
- Bootstrap
- Chart.js
- ReportLab

## ▶️ Installation

```bash
pip install -r requirements.txt
python app.py
```
